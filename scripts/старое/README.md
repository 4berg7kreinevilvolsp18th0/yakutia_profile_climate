# Скрипты «старое» / разовые

Сюда сложены one-off и отладочные скрипты, чтобы `scripts/` оставался рабочим контуром.

**Рабочие (остались в `scripts/`):**
- `profile_dashboard.py`
- `build_daily_profiles.py`
- `compute_inversion_v3.py`
- `download_aldan.py`
- `export_offline_dashboard.py`

Запуск из корня репозитория, например:

```powershell
py -3 scripts/старое/scan_aldan_index.py ...
py -3 scripts/старое/finish_aldan_full.bat
```
