# Карта станций

## Назначение

Расположение всех профилей из одного BUFR-файла (или batch) на карте lat/lon.

## Оси

- **X:** долгота, °
- **Y:** широта, °

## BUFR-дескрипторы

005002 (широта), 006002 (долгота)

## Цвета

`map_stations` — цвет маркеров

## Файл вывода

`stations_map.png` (один на файл BUFR)
