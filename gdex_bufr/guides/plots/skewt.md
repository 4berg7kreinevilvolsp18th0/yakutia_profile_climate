# Skew-T (лог-p)

## Назначение

Диаграмма Skew-T — основной инструмент анализа неустойчивости и влажности в вертикали. Ось давления логарифмическая, ось температуры наклонена на 45°.

## Что на графике

| Элемент | Описание |
|---------|----------|
| Красная линия | Температура воздуха T |
| Бирюзовая линия | Точка росы Td |
| Флажки | Ветер (U/V) через `barb_skip` уровней |
| Пунктир | Сухие/влажные адиабаты, линии смешения |

## BUFR-дескрипторы

| FXY | Поле |
|-----|------|
| 007004 | Давление |
| 012225 | Температура (NCEP non-standard) |
| 012227 | Точка росы |
| 011001 / 011002 | Направление / скорость ветра |

## Цвета (`plots.theme.colors`)

- `temperature` — линия T
- `dewpoint` — линия Td
- `barbs` — флажки ветра

## Условия построения

Минимум **2** уровня с T или Td.
