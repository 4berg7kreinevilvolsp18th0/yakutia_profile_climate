# Геопотенциальная высота

## Назначение

Высота изobaric levels — толщина слоёв, сравнение с моделью/климатом.

## Оси

- **X:** геопотенциальная высота, м
- **Y:** давление, гПа

## BUFR-дескриптор

010009 — geopotential height

## Цвета

`height`

## Когда пропускается

Если в сообщении нет 010009 (часто в старых ADPUPA).
