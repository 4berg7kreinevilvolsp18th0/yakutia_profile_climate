# Вертикальный профиль T / Td

## Назначение

Профиль температуры и точки росы по давлению — быстрый обзор стратификации без наклона Skew-T.

## Оси

- **X:** температура, °C
- **Y:** давление, гПа (лог. шкала, сверху — меньшее p)

## BUFR-дескрипторы

007004, 012225, 012227

## Цвета

`temperature`, `dewpoint`
