# Относительная влажность (RH)

## Назначение

Вертикальное распределение относительной влажности, рассчитанной из T и Td (MetPy).

## Оси

- **X:** RH, %
- **Y:** давление, гПа

## BUFR / расчёт

- Дескриптор 013003 (если есть в сообщении) — прямое RH
- Иначе: RH из 012225 + 012227 через формулу точки росы

## Цвета

`rh`
