# Термодинамические индексы

## Назначение

Текстовая сводка: LCL, CAPE, CIN, LFC, EL — оценка конvective potential без отдельного Skew-T.

## Показатели

| Индекс | Смысл |
|--------|--------|
| LCL | Уровень конденсации |
| CAPE | Положительная плавучесть |
| CIN | Подавление конвекции |
| LFC / EL | Уровни свободной / равновесной конвекции |

## Требования

Минимум **5** уровней с T и Td.

## Цвета

`thermo_box` — фон блока текста
