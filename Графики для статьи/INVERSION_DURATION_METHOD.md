# INVERSION_DURATION_METHOD

## Контекст

Радиозондирование дискретно: основные сроки **00** и **12 UTC** (шаг 12 ч).
Истинный момент начала/конца инверсии неизвестен → **interval censoring**.

## Определение события

- **ANY**: профиль inversion-positive, если `has_any_v3`.
- **G/E/HE**: по флагам `has_G`, `has_E`, `has_HE`.

Событие — максимальная последовательность положительных сроков без разрыва > 12 ч
(по умолчанию **без** склеивания через один пропущенный зонд).

## Длительность

- `duration_lower_h = t_last - t_first` (часы между первым и последним положительным сроком).
- Если известны соседние отрицательные сроки:
  - `duration_upper_h = t_next_negative - t_prev_negative`
  - `duration_midpoint_h = (lower + upper) / 2` — **оценка**, не точное значение.

## Цензирование

- `left_censored`: нет предыдущего отрицательного наблюдения.
- `right_censored`: нет следующего отрицательного наблюдения.
- `missing_observation_inside`: пропуск > 12 ч внутри события.

## Реализация

`revision_2026/inversion_duration.py` → `build_all_duration_events()`.

## Ограничения

- Нельзя утверждать «ровно 36 ч» только по 3–4 последовательным срокам без учёта censoring.
- `allow_one_missing_sounding=False` по умолчанию.
