# Пакет графиков для статьи по Алдану

Модуль рассчитан на структуру `profiles_long.csv` проекта `yakutia_profile_climate` и добавляется в существующий пакет без изменения декодера BUFR.

## Что включено

### Четыре основных рисунка статьи

1. Месячная полнота радиозондовых наблюдений.
2. Сезонные медианные профили температуры с межквартильным диапазоном.
3. Годовой ход повторяемости подтверждённых приземных инверсий для 00 и 12 UTC.
4. Межгодовая изменчивость повторяемости инверсий, скользящее среднее и наклон Сена.

### Дополнительные рисунки

- интенсивность инверсий по месяцам;
- высота верха инверсий по месяцам;
- сводка статусов QC;
- пучок профилей выбранного месяца;
- многолетний ход температуры на 925, 850, 700 и 500 гПа.

Все функции возвращают обычный объект `matplotlib.figure.Figure`, поэтому их можно использовать из CLI, Streamlit, Jupyter или текущего дашборда проекта.

### Три новых набора рисунков (type01–type03)

1. **Матрицы повторяемости по видам** (`type01_matrix_G/E/HE`) — год × месяц, % профилей с инверсией данного типа:
   - **G** — приземная (основание ≤ 30 м AGL);
   - **E** — приподнятая (основание ≤ 250 м AGL);
   - **HE** — высокая приподнятая (основание > 250 м AGL).
2. **Высоты** (`type02_height_*`) — по оси X высота верха AGL, по Y число инверсий: столбчатый, линейный, 12 панелей по месяцам, все месяцы вместе, плюс отдельный столбец на каждый месяц.
3. **Градиент γ** (`type03_gamma_*`) — γ = ΔT/Δz × 100 (°C/100 м) по X, число дней по Y: столбцы, линия, гистограмма; дополнительно boxplot γ по месяцам.

4. **Облако точек высота–толщина** (`11_top_height_vs_depth_joint`, `12_*`, `13_*`, `14_*`):
   - joint scatter + гистограммы (log N): X — высота верха AGL от поверхности станции (~679 м), Y — толщина слоя `depth_m`;
   - вертикальные опорные линии на высотах 850 / 700 / 500 гПа (барометрия ISA);
   - 12 панелей по месяцам на одном листе; boxplot толщины и высоты по месяцам;
   - отдельный joint plot γ vs высота верха.

Классификация G/E/HE считается в пакете статьи по подтверждённым слоям роста T (пороги confirm как у v2). Код gap-v3 проекта не изменяется.

## Установка в проект

Скопируйте:

```text
gdex_bufr/profile_climate/article_figures/
scripts/build_article_figures.py
scripts/article_figures_dashboard.py
article_figures_config.yaml
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Пакетная сборка

Из корня проекта:

```bash
python scripts/build_article_figures.py \
  --input "gdex_outputs/результаты-алдан/profiles_long.csv" \
  --output "gdex_outputs/article_figures" \
  --config article_figures_config.yaml
```

Результат:

```text
gdex_outputs/article_figures/
  figures/  # PNG 600 dpi + SVG
  tables/   # промежуточные таблицы CSV
  summary.json
```

По умолчанию заголовок не помещается внутрь рисунка: для журнальной вёрстки название и пояснение должны находиться в подписи. Для рабочих рисунков добавьте `--show-title`.

## Интерфейс

```bash
python -m streamlit run scripts/article_figures_dashboard.py
```

Интерфейс позволяет:

- загрузить CSV или указать путь;
- выбрать станцию и сроки;
- менять пороги QC и алгоритма инверсии v2;
- выбирать палитру и язык;
- сохранять PNG/SVG и таблицы;
- одним нажатием собирать ZIP с четырьмя основными рисунками статьи.

## Важные методические решения

### Полнота

Полнота считается по уникальным сочетаниям `date + cycle` относительно двух ожидаемых сроков в сутки. Первый и последний месяцы ограничиваются фактической границей массива, а месяцы за пределами наблюдений показываются серым как отсутствующие, а не как 0%.

### Сезонные профили

Каждый профиль сначала интерполируется на общую сетку давления 500–925 гПа с шагом 25 гПа. Интерполяция выполняется только внутри фактически наблюдаемого диапазона конкретного зонда; экстраполяция запрещена. После этого рассчитываются медиана и 25–75-й процентили.

### Инверсии

Реализована текущая логика v2 проекта:

1. непрерывный рост температуры от нижнего уровня более чем на `min_inversion_delta_c`;
2. не менее `confirm_drop_levels` последовательных шагов падения;
3. подтверждающий слой толщиной не менее `confirm_depth_hpa` с суммарным падением температуры.

Кандидаты без устойчивого падения имеют `rejected_no_lapse` и не входят в повторяемость подтверждённых инверсий.

### QC нижнего уровня

Строгий журнальный режим по умолчанию исключает профили, у которых давление нижнего уровня выше 960 гПа (10 профилей в текущем массиве Алдана). Контроль расхождения высоты нижнего уровня с отметкой станции вынесен в отдельный переключатель `use_surface_height_qc`, потому что восстановленные высоты требуют самостоятельной проверки источника `height_m`. Все пороги доступны в YAML и интерфейсе. Для полного совпадения с базовой логикой проекта отключите `strict_surface_qc`.

## Встраивание в существующий CLI

Можно импортировать pipeline:

```python
from gdex_bufr.profile_climate.article_figures.config import AnalysisConfig, FigureStyle
from gdex_bufr.profile_climate.article_figures.pipeline import build_all

build_all(
    "gdex_outputs/результаты-алдан/profiles_long.csv",
    "gdex_outputs/article_figures",
    AnalysisConfig(),
    FigureStyle(),
)
```
