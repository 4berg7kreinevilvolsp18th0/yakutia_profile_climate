# Исправленные высоты инверсий — Алдан

Пересчёт с реальных профилей `gdex_outputs/far_east/stations/aldan/profiles_long.csv`.

## Что было не так

1. **Инверсии.** Сегменты искали в порядке давления, а `height_m` на части уровней не был монотонен. Отсюда слои с `depth_m ≤ 0` и `top ≤ base`.
2. **Неполные данные на графиках.** Грубые бины (до 4000 м, `right=False`) отбрасывали высокие слои; пустые бины пропадали.
3. **Разная ширина столбцов.** Столбцы рисовали пропорционально ширине интервала (50 м vs 1500 м), из‑за этого низкие слои визуально «сжимались».
4. **Теплокарты G.** Общая шкала 0–5000 м делала приземные слои почти чёрными.

## Исправление

- вертикальная координата поиска — `height_m`; одинаковые высоты в профиле усредняются;
- алгоритм слоёв — **gap-v3** (γ = 100·dT/dz, склейка gap < 100 м, ΔT ≥ 0.3 °C);
- `depth_m = top − base`; G ≤ 30 м AGL, E 30–250 м, HE > 250 м;
- все бины на месте, overflow `≥4500` м, ничего не отбрасывается;
- столбчатые диаграммы — **одинаковая ширина столбцов**, подписи интервалов на оси;
- теплокарты медианы — шкала по данному типу (98-й процентиль), а не 0–5000 для всех.

Приземная повторяемость статьи (fig03/fig04) по-прежнему считается **legacy v2**. Слои G/E/HE и рисунки высот — по исправленному gap-v3.

## Набор рисунков

- `00`–`10` — QC и климат высот G/E/HE;
- `fig01`–`fig04`, `extra01`–`extra04` — основные рисунки статьи;
- `type01`–`type03` — матрицы, высоты (все месяцы + G/E/HE), γ.
